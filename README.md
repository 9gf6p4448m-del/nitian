## 操作

新版首頁按「開始交手」。雙方45生命、各自相同十張牌、每回合抽五張且最多出三張，雙方手牌公開。

1. 點自己的手牌，點目前共同軌道的任一間隙，再按「確認落牌」。確認前可改選，確認後不能撤回／移動。
2. 雷衛依同一套合法規則落一張或停手。如此交替，先放的牌仍可被後續新牌插入前後。
3. 「本回合停手」表示放棄本回合剩餘出牌機會，對手仍可用完額度；兩方都停止或達三張上限後按「共同結算」。
4. 預估僅計目前軌道（及已選位置的待確認牌），不包含對手尚未決定的牌；不是本回合結果保證。
5. 下一回合交換先手。雙方護盾／暫態清除、雷量保留，所有手牌棄置重抽。

可在首頁指定首回合先手，或戰鬥中的「重新開始」選交換首手。相同種子交換首手不改雙方各自的起始牌序；後續結果仍取決於決策。AI為有限兩層前瞻，不讀未來牌序，不宣稱全局最佳。

### 看懂倒刺與結算

首頁「先學倒刺與順序」或上方「教學」可開獨立示範；隨時可略過，不改正式交手、牌序或戰績。
落牌只是排順序，軌道結算走到那張牌才發動。倒刺要先執行，之後受到未閃避的攻擊且仍存活，才在同回合立即反傷6；完全格擋也反傷，閃避或被打死不反傷。未觸發的倒刺不帶入下回合。

共同結算時可「暫停結算」→「下一個事件」，查看誰對誰、護盾擋多少、生命與雷量前後值。標準每事件約1秒，可兩倍速或略過；減少動態效果仍可手動重看。
每招下方有試算／實際原因，回合後有總結，包含防禦未用到、反傷與死亡後未執行的牌。「重看本回合」逐事件回放，沒有第二次扣血或保存戰績；敗北後也能重看最後一回合。
開啟教學／設定等視窗會暫停正式結算；關閉後維持原本的手動暫停狀態。

### 原版對照操作

在新版首頁點「進入原版借招對照」，原版首頁亦可切回新版。

1. 選試煉模式與種子，按「開始借招」。引導可關閉。
2. 點手牌，再點四個插入區之一。最多三張，可移動、撤回、清空。
3. 點已編排的牌，在詳情列用「同區↑／↓」調序。
4. 同時看生命、護盾、雙方雷量預估，再出手；演出可略過。
5. 下一回合清除護盾、保留雷量，全部舊手牌已進棄牌堆。

手機軌道可以獨立上下捲動；手牌與詳情在軌道下方，出手列固定於畫面底部。

## 新版三個優先試玩情境

- **交換首手**：相同種子打一局後交換首手，觀察先放／最後放牌的差異；不是以單局勝敗判定平衡。
- **截雷與提前奉還**：有汲能、奉還時觀察對手引雷的位置，嘗試在資源被拿走前兌現；也觀察是否每次都有固定答案。
- **提早停手**：選擇只出一兩張，觀察剩餘反應權交給對手的代價、是否值得保留雷量，以及每回合操作是否太慢。

### 原版三個比較情境

- **初見雷衛／30 HP**：保留引導，試引雷＋護身＋奉還，把奉還移至敵盾前後比較。
- **紙上試煉／48 HP**：固定牌序，對照規格中的四回合43 HP路線，再試搶攻及保命。
- **須彌山門／48 HP**：關引導、換種子。觀察自己會不會重新判斷，而不是套固定配對。

「紙上試煉」是命名牌序 fixture，不宣稱由特定數字種子隨機產生。
種子模式僅在相同模式、引導設定、種子與決策下保證相同結果。
牌序不預先揭露；可以查看公開敵人模式和自己當下的手牌。

## 手機 PWA

首次保持連線，等頁面完整載入。Android Chrome可按頁內「安裝到手機」；
若瀏覽器不提供安裝提示，從瀏覽器選單安裝。iPhone／iPad用 Safari 的分享選單
選「加入主畫面」。安裝須本人在系統介面確認，網頁無法代按。

載入離線快取後，即使斷網重新開啟仍可玩。新版本載入後有更新提示，
確認更新會捨棄未完成的局。若長時間未更新，連線重開或重新整理一次；
仍停在舊版可移除本網站的快取後重開，但清除網站資料會刪除本機紀錄。
頁尾UTC建置時間及 `version.json` 可核對版本。

## 紀錄與隱私

設定、最近20局完成紀錄與最多600字回饋保存在本機 localStorage，沒有遠端分析。
支援匯出JSON，包含種子、模式、引導、編排、事件前後資源、編排時間及撤回次數。
新版採獨立的 `nitian.duel.*.v1` 設定／紀錄鍵，不覆蓋原版資料；JSON有 `variant: alternating-v1`、首回合先手、雙方每回合手牌、逐手落牌／停手歷程、最終軌道與事件。新版決策時間是整回合耗時（包含AI等待），不記不存在的撤回操作。
本機容量或權限出錯會顯示提示，遊戲仍可玩、當局可匯出。中途存檔恢復不在S0範圍。
