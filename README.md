# 逆天 NITIAN · S0

把你的招式插入天神的行動軌道，借走雷霆，再親手奉還。

單場玩法驗證原型，繁體中文、2D 原創 SVG。程式及自動化測試可驗證結算，
不能證明真人覺得好玩。尚無獎勵、遺物、三場構築或帝釋天 Boss。

## 啟動與驗證

需要 Node.js 24.16 或相容新版、npm、Git。先 `npm ci`。

```sh
npm run dev
# 開啟終端列出的 http://127.0.0.1:5173/nitian/
npm test
npm run test:coverage
npm run build
npm run test:e2e
```

瀏覽器測試使用本機 Google Chrome。沒有 Chrome 時需先安裝或將
`playwright.config.ts` 改成實際可用的瀏覽器設定；不得跳過後宣稱通過。
`npm run preview -- --port 4173` 可預覽 production build，包含離線 PWA。
開發模式不註冊 service worker。

規則／本機儲存核心設80%四項 coverage 門檻；React介面另以真實瀏覽器流程測試。
E2E涵蓋勝敗、重開、編排、正常／略過演出、儲存故障、離線重載及兩種視窗尺寸。

## 操作

1. 選試煉模式與種子，按「開始借招」。引導可關閉。
2. 點手牌，再點四個插入區之一。最多三張，可移動、撤回、清空。
3. 點已編排的牌，在詳情列用「同區↑／↓」調序。
4. 同時看生命、護盾、雙方雷量預估，再出手；演出可略過。
5. 下一回合清除護盾、保留雷量，全部舊手牌已進棄牌堆。

## 三個優先試玩情境

- **初見雷衛／30 HP**：保留引導，試引雷＋護身＋奉還，把奉還移至敵盾前後比較。
- **紙上試煉／48 HP**：固定牌序，對照規格中的四回合43 HP路線，再試搶攻及保命。
- **須彌山門／48 HP**：關引導、換種子。觀察自己會不會重新判斷，而不是套固定配對。

「紙上試煉」是命名牌序 fixture，不宣稱由特定數字種子隨機產生。
種子模式僅在相同模式、引導設定、種子與決策下保證相同結果。
牌序不預先揭露；可以查看公開敵人模式和自己當下的手牌。

## 手機 PWA

首次保持連線，等頁面完整載入。Android Chrome可按頁內「安裝到手機」；
若瀏覽器不提供安裝提示，從瀏覽器選單安裝。iPhone／iPad用 Safari 的分享選單
選「加入主畫面」。安裝須本人在系統介面確認，網頁無法代按。

載入離線快取後，即使斷網重新開啟仍可玩。新版本載入後有更新提示，
確認更新會捨棄未完成的局。若長時間未更新，連線重開或重新整理一次；
仍停在舊版可移除本網站的快取後重開，但清除網站資料會刪除本機紀錄。
頁尾UTC建置時間及 `version.json` 可核對版本。

## 紀錄與隱私

設定、最近20局完成紀錄與最多600字回饋保存在本機 localStorage，沒有遠端分析。
支援匯出JSON，包含種子、模式、引導、編排、事件前後資源、編排時間及撤回次數。
本機容量或權限出錯會顯示提示，遊戲仍可玩、當局可匯出。中途存檔恢復不在S0範圍。

## 部署

Vite基底固定 `/nitian/`。首次建立GitHub repository並啟用 Pages 的 `gh-pages` 根目錄。

```sh
npm run build
npm run deploy:pages
```

部署前先提交原始碼，讓 `dist/version.json` 的來源提交可核對。
推送後檢查 `gh api repos/9gf6p4448m-del/nitian/pages/builds/latest`，再驗線上網址與版本。
相同 build 的service worker依資產雜湊命名快取，更新需使用者確認。
